## 0. 한 줄

**시왕의 자리 앞에 늘어선 열두 대문. 문은 닫혀 있고, 대문을 지나지 못한 넋들이 문 앞에 줄을 선 채 원귀가 되어 간다.**
3막이자 마지막 지역. *힘으로 밀어붙일 수 없는 상대*(빗장·방어)를 파티의 상태 언어로 푸는 법을 묻고, 마지막에 **원정 내내 해원한 기록**이 결말을 바꾼다.

> 왜 대문이 닫혀 있나: 열두째 대문의 빗장을 *이름 없는 장수의 원귀*가 붙들고 놓지 않는다. 그래서 1막 나루와 2막 마을에도 넘어가지 못한 넋이 쌓였다 — 세 지역을 잇는 캠페인 줄기다(백로그 #3).

## 1. 지역의 성격

| 항목 | 내용 | 근거 |
|---|---|---|
| 무대 | 대문이 한 줄로 늘어선 긴 회랑(척추) + 대문마다 곁방 1~2개. **원정 하나가 대문 넷을 지난다**(첫째~넷째 · 다섯째~여덟째 · 아홉째~열두째). 고리 통로가 적어(−2) 되돌아가기 어렵다. 대문 방은 통행을 요구한다(지전 1 · 문사재 문답 · 문지기 전투) | 저승 원문과 12대문, 안도령에서 12대문을 지나는 대목(무속 지식 정리 §1.2·§4.2) |
| 원귀 계열 | **억울귀 · 무장 원귀 · 객귀 · 굶주린 넋** | 차례를 잃은 넋(억울귀), 싸움터에서 죽은 이름 없는 군졸(무장 원귀), 객사(객귀), 사자밥을 못 받은 넋(굶주린 넋) |
| 시왕 | **적으로도 인물로도 나오지 않는다.** "시왕의 자리"라는 틀과, 판결하지 않는 거울(업경대)로만 | E10, 매체 조사(저승 재판 구조는 신과함께의 고유 요소) |
| **대표 압박**(E3) | **P5 방어·피해 상한**(빗장 · 큰 방어도) · **P1 누적**(한이 깊어짐) | 1막 P1·P13, 2막 P4·P3. 상한(P5)이 느리게 만들고, 누적(P1)이 느림을 벌한다 → 답은 *상태 피해*(상흔 · 명부 · 붕괴) |
| 핵심 보급품 | **향**(업경대 · 혼 부르는 등 · 덫), **쌀**(사자밥 · 줄 선 넋) | 세 지역이 보급품 여섯을 나눠 맡는다: 1막 촛불·지전, 2막 술·부적, 3막 향·쌀 |
| 덫 | 닫히는 대문(기습당함) · 업경대 파편(귀기 +15) · 무쇠 빗장(상처) | |
| 재료 | 녹슨 투구끈(무장 원귀 → 각인: **장단**), 타다 남은 소지, 떠돌이 짚신, 빈 제기 | [본진](06-base.md) §3 |

## 2. 이 지역이 가르치는 것

| 순서 | 가르치는 것 | 어디서 |
|---|---|---|
| 1 | **빗장**(새 메커니즘): 한 플레이어 턴에 잃는 체력에 상한이 있다. **상흔·명부·붕괴는 상한을 넘는다** → 폭딜 파티가 처음 막히고, 상태 파티가 길을 연다 | 빗장 지키는 넋(15) |
| 2 | **큰 방어도와 누적**: 방어 12~18을 세우며 공격이 커진다. 미루면 손해 | 녹슨 창 군졸 넋, 방패 든 군졸 넋 |
| 3 | **새치기·끌어당김**(진형 교란 복습) | 줄 선 넋, 깃발 아래 군졸 |
| 4 | **번지는 홀림 + 카드 사용 처벌(P10)**: 진형 전체를 홀리고, 홀린 영웅이 카드를 낼 때마다 원귀가 방어도를 얻는다 | 엘리트 *문서 잃은 넋* |
| 5 | **쓰러진 영웅 노리기** 복습 | 엘리트 *사자밥 빼앗긴 넋*, 최종 보스 2단계 |
| 6 | **해원과 빗장의 맞바꿈**: 혼백 보스는 백을 살려 둔 채 혼을 쓰러뜨려야 풀리는데, 백이 서 있는 동안 혼에 빗장이 걸린다 | 보스 *혼백이 갈린 원귀* |
| 7 | **업경대와 고풀이**: 원정에서 해원한 수가 최종 보스의 매듭을 미리 풀고, 매듭 넷을 *서로 다른 상태*로 풀어야 해원된다 | 업경대 비추기 → 최종 보스 *빗장을 놓지 못한 장수* |

### 보스 둘 — 같은 지역, 다른 시험

| 보스 | 시험하는 것 | 해원의 선택 |
|---|---|---|
| **혼백이 갈린 원귀** | 대상 우선순위와 상태 피해. 백(앞, 방어 16)을 먼저 치우면 혼의 빗장이 풀려 빨리 끝난다 | 그러면 *처치*다. **해원하려면 백을 살려 둔 채, 빗장 22를 안고 혼을 상태 피해로 깎아야** 한다. 혼을 먼저 대문 안으로 보내야 백도 무덤으로 돌아간다(혼·백 관념, 무속 지식 정리 §4.6) |
| **맨 앞에 선 굶은 넋** | 무리전 + 굿상 갉아먹기 + 새치기. 2단계에 공격이 쌓인다 | **쌀 3**을 길굿 끼니에 쓸까, 사자밥으로 차릴까. 차리면 해원 확정 + 그 턴 뒤에 선 넋들이 행동하지 않는다 |

### 최종 — 빗장을 놓지 못한 장수

북쪽 변방 관문을 지키던 가상의 장수. 지원군은 끝내 오지 않았고, 그는 성문을 열지 않은 채 쓰러졌다. 죽어서도 열두째 대문의 빗장을 붙들고 있다.

| 단계 | 내용 |
|---|---|
| 1단계 *성문* (체력 50%까지) | 순환: 성문 호령(수문 군졸 방어도 8, 자신 공격 +1 누적) → 빗장 내리치기 15 → 성벽 화살 후열 6×2 → 성문을 닫아라 방어 24. **수문 군졸이 하나라도 서 있으면 빗장 16** — 군졸부터 치울지가 첫 결정이다 |
| 2단계 *장수* | 빗장이 풀리고 직접 나선다. 장수 돌격 10×2 · 쓸어 베기 전체 8 · 낙오자 다그치기(쓰러진 영웅 18) · 한이 깊어짐(방어 20, 공격 +2 누적). 반회피: 쓰러진 영웅을 먼저 노린다(E7) |
| **고풀이 해원** | 매듭 8종 중 **4개**를 풀고 쓰러뜨린다: ① 점지 ② 상흔 ③ 명부 ④ 넋흔들림이 장수에게 걸림 ⑤ 장단 3 이상으로 턴을 마침 ⑥ 굿상에 설치물이 있는 채로 턴을 마침 ⑦ 부적 카드로 장수에게 피해 ⑧ 진형이 바뀐 채로 턴을 마침. 한 번 풀린 매듭은 다시 맺히지 않는다 |
| **업경대 비추기**(바로 앞 방 고정) | 이번 원정의 해원 수: 0~4 귀기 +10 / 5~9 해원 조건 공개 + 첫 턴 드로우 +1 / **10~14 매듭 1개가 풀린 채 시작** + 체력 +15% / **15 이상 매듭 2개** + 체력 +15%. 향 1이면 한 단계 위, 만신은 해원 수 +2 |

- 매듭 넷은 어떤 3인 조합도 풀 수 있다: 영웅마다 상태 3종을 만들고(시그니처·주·부), 장단(기세)과 진형(돌격)은 모든 파티에 있다. 조합에 따라 *어떤 넷*이 쉬운지가 다를 뿐이다.
- "고풀이처럼 맺힌 매듭을 하나씩 풀어 주자, 장수는 마침내 빗장에서 손을 떼고 스스로 문을 연다. 문 앞에서 기다리던 넋들이 차례로 들어간다." — 결말이 처형이 아니라 **배웅**이다.

## 4. 파티 구성과 지역의 궁합

해원 조건이 있는 원귀 11종(진형 2 · 장단 2 · 명부 2 · 굿상 1 · 부적 1 · 상흔 1 · 점지 1 · 넋흔들림 1, **공용 상태 8/8종**). 보스 셋은 상태가 아닌 조건(졸개 생존 · 공물 · 고풀이)이라 모든 파티가 노릴 수 있다.
- 3인 조합이 해원할 수 있는 원귀는 **최소 7종 · 중앙 9종 · 최대 11종**이다.

| 파티 성향 | 이 지역에서 |
|---|---|
| **상흔·명부 파티**(포수·작두박수 / 차사·만신·법사) | 빗장을 넘는 피해를 낸다 — *전투*에서 이 지역의 강자. 1막 약자 *만신 + 포수 + 차사*(해원 6/11 → 7/12 → 7/11)는 해원 수는 중간이지만 빗장 원귀 셋과 혼백 해원 경로에 가장 잘 맞는다 |
| 넋흔들림 파티(승려·작두박수·법사) | 붕괴로 빗장을 연다. 업경대 앞 넋 해원 |
| 장단·진형 파티(잽이·탈꾼·승려) | 무장 원귀(녹슨 창 · 깃발 기수)와 객귀 둘을 해원한다. 세 지역 모두에서 낮던 *잽이 + 승려 + 탈꾼*이 7/11로 올라선다 |
| 폭딜 위주 파티 | 빗장 때문에 가장 고생한다. 수문 군졸·백을 먼저 치우는 *처치* 경로는 열려 있다 |

**세 지역 비교** (`region_check.py` 지역 비교, 그 지역 해원 원귀 중 해원 가능 비율)

| 3인 조합 | 1막 | 2막 | 3막 |
|---|---:|---:|---:|
| 만신 + 포수 + 차사 | 6/11 | 7/12 | 7/11 |
| 잽이 + 포수 + 탈꾼 | 6/11 | **10/12** | 8/11 |
| 잽이 + 승려 + 탈꾼 | 7/11 | 7/12 | 7/11 |
| 승려 + 법사 + 차사 | 9/11 | **6/12** | 7/11 |
| 승려 + 작두박수 + 법사 | 8/11 | 9/12 | 8/11 |

- 모든 지역에서 가장 낮은 비율도 50% 이상이다(해원 0종인 조합 없음).
- 지역에 따라 해원 비율이 25%p 이상 달라지는 조합 10/56 — 지역 선택이 파티 선택과 맞물린다(기둥 P1).

## 6. 재현 윤리 점검

| 항목 | 처리 |
|---|---|
| **시왕** | 적으로도, 말하는 인물로도 나오지 않는다. "시왕의 자리"라는 장소와 **판결하지 않는 거울(업경대)** 로만 나온다. 업경대는 이번 원정에서 *풀어 준 넋*을 비출 뿐 영웅을 심판하지 않는다 |
| 피할 고유 요소 | 저승 재판·변호(신과함께), "49일의 시련"(7 Trials의 간판 문구), 검은 갓 저승사자(도깨비·KPDH)를 쓰지 않는다. 재판 장면·판결·변론이 없다. 검사기가 '변호사·국선·변론'을 금지어로 잡는다 |
| 사자(문사재) | 적이 아니라 *문답하는 문지기*로, 사재삼성거리의 해학 그대로. 군졸 차림(1막과 같다) |
| **최종 보스** | **신령이 아닌 큰 원귀**다. 가상 왕국 북쪽 변방의 *이름 없는* 장수 — 실존 장군(최영 등)·실제 전쟁·실제 관문을 떠올리게 하는 이름과 사건을 쓰지 않는다. 장군신으로 모셔지는 신령과 섞이지 않게 "모셔지지 못해 원귀로 남았다"는 쪽으로 그린다. 결말은 처형이 아니라 빗장을 놓고 문을 여는 배웅 |
| 무장 원귀 | 싸움터의 죽음은 "쓰러졌다"까지만. 피·상처 묘사 없음. 방패 군졸의 해원 '오랜 상처를 짚어 준다'는 마음의 상처로 연출 |
| 혼백 보스 | 혼·백은 일반 관념이다. 백은 *흰 그림자*로 그리고 시신·좀비 이미지를 쓰지 않는다 ⚠️ 감수 대상 |
| 바리공주 모티프 | 약수·노역·나화(꽃)·서천서역은 *물건과 이벤트 구조*로만 빌린다. 바리공주(무조신, 감수 등급 중간)를 인물로 등장시키거나 이름을 게임 문장에 쓰지 않는다("약수를 구하러 저승까지 간 옛이야기처럼"). 무가 사설 인용 없음 |
| 강림·까마귀 | 차사본풀이의 까마귀 실수와 행기못은 사건·물건으로만 쓴다. 강림을 인물로 쓰지 않는다 |
| 고풀이 | 씻김굿의 고풀이(일곱 매듭)는 *해원의 은유*로 규칙에 옮겼다. 지정 굿의 절차를 그대로 재현하지 않는다(감수 등급 중간) |
| 업경대·적패지·사자밥 | 낮은 등급(설화·일반 문화) 요소 |
| 신령 가호 | 문신·신장은 범주 이름이다. 실존 인물신 없음 |

## 9. 엔진 지원 필요 (반복 2에서 구현)

새 메커니즘 3개 + 지역 2의 **공물 행동 일반화**([지역 2](05-region2.md) §9.2, 맨 앞에 선 굶은 넋의 '사자밥 차리기' 쌀 3)를 함께 쓴다. 3단계 패턴은 쓰지 않았다(엔진은 2단계까지).

### 9.1 빗장 — 한 턴 피해 상한

| 항목 | 명세 |
|---|---|
| 규칙 | **빗장 N**: 한 플레이어 턴 동안 이 원귀가 잃는 체력의 합이 N에 닿으면, 그 턴 남은 피해는 체력을 깎지 않는다. 방어도가 막은 양은 세지 않는다(방어도는 보통처럼 먼저 깎인다). 적 턴이 시작되면 0으로 돌아간다 |
| 상한 밖 | ① **상흔**(출혈) 피해 — 적 턴 시작에 들어온다 ② **명부**(파멸) 판정 — 플레이어 턴 종료에 체력과 관계없이 쓰러뜨린다 ③ **붕괴** 상태인 동안의 모든 피해 — 붕괴가 빗장을 연다. 그래서 어느 3인 조합에도 답이 있다(상흔·명부·넋흔들림을 모두 못 만드는 영웅은 잽이·탈꾼뿐이고, 둘만으로는 3인이 안 된다) |
| 조건 | 데이터 문장: `빗장 15` · `빗장 22: 1단계에서 떠도는 백이 서 있는 동안` · `빗장 16: 1단계에서 수문 군졸이 하나라도 서 있으면`. 구현은 문장 해석보다 원귀 정의에 `cap: {n, phase?: 1, whileAlive?: enemyId}` 필드를 더하는 쪽을 권한다(이 문서를 정본으로 지역 데이터에 필드를 추가해도 된다) |
| 표시 | 의도 옆에 빗장 아이콘과 이번 턴 남은 양 |
| 가호 | 나화 한 송이: 0코스트 '꽃 던지기'(소멸) — 원귀 하나의 방어도 0 + 이번 턴 빗장 해제 |
| 봇 | 피해 예측에 상한을 적용하고, 빗장 원귀 앞에서 상흔·명부·넋흔들림 카드 가치를 올린다 |
| 쓰는 곳 | 빗장 지키는 넋(15) · 혼백이 갈린 원귀(22, 1단계 · 백 생존) · 빗장을 놓지 못한 장수(16, 1단계 · 수문 군졸 생존) · 가호 나화 한 송이 |
| 대체 동작 | 구현 전: 상한 없음(문장은 표시만). P5가 방어도만으로 약해진다 |

### 9.2 업경대 — 원정 해원 수를 읽는 이벤트

| 항목 | 명세 |
|---|---|
| 읽는 값 | 이번 원정에서 해원한 원귀 수(원귀 단위, 무리 해원 포함, 손님 배웅 같은 특수 전투의 '좋게 보냄'도 1로 친다). 원정 계층(`src/game/run` 해원록)이 이미 센다 |
| 구간 | 0~4 / 5~9 / 10~14 / 15+. 1막 원정 시뮬레이션(v0.2.1, 조합당 200회)의 해원 수가 원정당 평균 약 10(무리 원귀는 마리마다 센다)이라, 중앙의 파티가 매듭 1개를 미리 푼다. 향 1 → 한 구간 위. 만신 → 해원 수 +2 |
| 결과 전달 | '매듭 k개가 풀린 채 시작'을 다음 final 전투에 넘긴다(§9.3 의 `knotsPreset = k`). 무작위가 아니라 *그 파티가 풀기 어려운 매듭*부터 푼다(조합의 상태 생산 목록에 없는 매듭 우선) |
| 쓰는 곳 | 업경대 비추기 · 빗장을 놓지 못한 장수 |
| 대체 동작 | 구현 전: '거울 앞에 선다'가 해원 조건 공개 + 첫 턴 드로우 +1 로 고정 |

### 9.3 고풀이 — 여러 매듭으로 해원

| 항목 | 명세 |
|---|---|
| 해원 종류 | `knots`: 데이터 `haewon.knots`(8개) · `knots_needed`(4). 해원 문장 '맺힌 매듭 넷을 푼 뒤 쓰러뜨린다(고풀이)'는 지금 해석기가 'none'으로 읽는다(검사기가 다른 종류로 잘못 읽히지 않는지 확인함) |
| 판정 시점 | ①~④ 점지·상흔·명부·넋흔들림: 장수에게 그 상태가 1 이상 걸린 순간 ⑤ 장단 3 이상으로 플레이어 턴 종료 ⑥ 플레이어 턴 종료 시 굿상 설치물 ≥ 1 ⑦ 부적(토큰) 카드의 피해가 장수에게 들어감(방어도에 막혀도 인정) ⑧ 진형이 바뀐 채로 플레이어 턴 종료(`formChanges > 0`). 한 번 풀리면 영구 |
| 해원 | 풀린 매듭 ≥ 4(업경대 미리 풀기 포함)인 상태로 장수를 쓰러뜨림. 수문 군졸은 장수를 따라 해원(`follows`) |
| 표시 | 장수 머리 위 매듭 8칸, 풀린 것은 밝게. 매듭 이름은 해원록 서고가 공개 |
| 봇 | 아직 안 풀린 매듭을 만드는 카드의 가치를 올린다 |
| 대체 동작 | 구현 전: 장수를 해원할 수 없다(처치만) |
