## 0. 한 줄

**시왕의 자리 앞에 늘어선 열두 대문. 문은 닫혀 있고, 대문을 지나지 못한 넋들이 문 앞에 줄을 선 채 원귀가 되어 간다.**
3막이자 마지막 지역. *힘으로 밀어붙일 수 없는 상대*(빗장·방어)를 파티의 상태 언어로 푸는 법을 묻고, 마지막에 **원정 내내 해원한 기록**이 결말을 바꾼다.

> 왜 대문이 닫혀 있나: 열두째 대문의 빗장을 *이름 없는 장수의 원귀*가 붙들고 놓지 않는다. 그래서 1막 나루와 2막 마을에도 넘어가지 못한 넋이 쌓였다 — 세 지역을 잇는 캠페인 줄기다(백로그 #3).
>
> ⟨반복 4⟩ **차사가 걷는 길을 거꾸로 되짚는 원정** (G-06): 차사는 넋을 데리러 올 때 마을 본향당에 들러 명부를 확인받고 → 집 → 대문 밖 → 강 → 열두 문 순서로 간다([신과함께 출처 조사](research/lore/singwa-sources.md) S-1 · S-11 ④). 파티는 그 길을 반대로 — 강(1막 나루) → 집과 대문(2막 마을) → 열두 문(3막) — 되짚으며, 그 길에서 차사를 만나지 못한 넋들을 보낸다.

### 1.1 열두 대문은 무엇인가 — 넋을 보내는 굿의 문 ⟨반복 4⟩

근거: 제주 시왕맞이의 **질침**(차사영맞이) — 굿당에 댓가지로 저승의 열두 문을 세우고, 길을 아홉 단계로 닦는 모습을 노래와 춤으로 보인 뒤, 심방이 문을 하나씩 열어 영혼을 보낸다([신과함께 출처 조사](research/lore/singwa-sources.md) S-6). 지정 굿의 순서를 그대로 옮기지 않고 *이미지와 진행 표시*로만 빌린다(감수 등급 중간).

| ID | 무엇 | 게임에서 | 반영 |
|---|---|---|---|
| G-01 | **열두 대문 = 댓가지 문** | 3막 대문은 거대한 성문이 아니라 **댓가지를 엮어 세운 굿판의 문**이 끝없이 이어진 회랑이다. 무쇠 빗장은 **열두째 대문에만** 있다(장수가 붙든 것) | 지역 소개·대문 통행 문장(`region3.json`), 카드 삽화 어휘 `gate` 배경(`tools/art/vocab.mjs` → `data/art/cards.json` 67장), 아트 방향 [10-presentation](10-presentation.md) §4.10 |
| G-02 | **아홉 단계 길닦기** | 대문 사이 길을 닦아 가며(⟨반복 5⟩ 들어설 때 · 길굿마다 · 넋을 풀어 보낸 싸움마다) ①돌아보기(입장) ②풀 베기 ③그루 파기 ④흙 고르기 ⑤돌 치우기 ⑥밀대 ⑦비질 ⑧물 뿌리기 ⑨띠 깔기가 한 칸씩 찬다. 대문 앞 길이 거칠다는 문장(「길이 닦여야 문이 열린다」) | ⟨반복 5⟩ 최종 원정의 진행 표시(지도 「길닦기 n/9」) + 「다 채우면 업경대 구간 +1」 — §14.1 (업경대 구간 분포 다시 잼) |
| G-04 | **열넷의 빈 자리** | 회랑 끝, 업경대 뒤에 **열 왕과 네 대왕(지장·생불·좌두·우두)의 자리 열넷이 비어 있다**. 아무도 앉아 있지 않다 — 판결이 없다는 것을 그림으로 보인다 | 업경대 비추기 문장, 아트 방향 |
| G-05 | **결말 너머 = 꽃이 핀 산** | 장수가 빗장을 놓고 열두째 대문이 열리면, 그 너머는 지옥이 아니라 **환생꽃과 숨살이꽃이 핀 산**(서천꽃밭 계열, 무속 저승의 「뒷동산 꽃밭」)이다 | 장수 해원 문장 · 좋은 결말 문장(`campaign.json endings.good`) · 지역 소개 |

- 지옥 이름(도산·화탕 …)과 형벌 장면은 이 지역 어디에도 쓰지 않는다(§6).

## 2. 이 지역이 가르치는 것

| 순서 | 가르치는 것 | 어디서 |
|---|---|---|
| 1 | **빗장**(새 메커니즘): 한 플레이어 턴에 잃는 체력에 상한이 있다. **상흔·명부·붕괴는 상한을 넘는다** → 폭딜 파티가 처음 막히고, 상태 파티가 길을 연다 | 빗장 지키는 넋(15) |

|---|---|---|
| **혼백이 갈린 원귀** | 대상 우선순위와 상태 피해. 백(앞, 방어 16)을 먼저 치우면 혼의 빗장이 풀려 빨리 끝난다 | 그러면 *처치*다. **해원하려면 백을 살려 둔 채, 빗장 22를 안고 혼을 상태 피해로 깎아야** 한다. 혼을 먼저 대문 안으로 보내야 백도 무덤으로 돌아간다(혼·백 관념, 무속 지식 정리 §4.6) |
| **맨 앞에 선 굶은 넋** | 무리전 + 굿상 갉아먹기 + 새치기. 2단계에 공격이 쌓인다 | **쌀 3**을 길굿 끼니에 쓸까, 사자밥으로 차릴까. 차리면 해원 확정 + 그 턴 뒤에 선 넋들이 행동하지 않는다 |

### 최종 — 빗장을 놓지 못한 장수

북쪽 변방 관문을 지키던 가상의 장수. 지원군은 끝내 오지 않았고, 그는 성문을 열지 않은 채 쓰러졌다. 죽어서도 열두째 대문의 빗장을 붙들고 있다.

| 단계 | 내용 |
|---|---|
| 1단계 *성문* (체력 50%까지) | 순환: 성문 호령(수문 군졸 방어도 8, 자신 공격 +1 누적) → 빗장 내리치기 15 → 성벽 화살 후열 6×2 → 성문을 닫아라 방어 24. **수문 군졸이 하나라도 서 있으면 빗장 16** — 군졸부터 치울지가 첫 결정이다 |
| 2단계 *장수* | 빗장이 풀리고 직접 나선다. 장수 돌격 10×2 · 쓸어 베기 전체 8 · 낙오자 다그치기(쓰러진 영웅 18) · 한이 깊어짐(방어 20, 공격 +2 누적). 반회피: 쓰러진 영웅을 먼저 노린다(E7) |
| **고풀이 해원** | 매듭 8종 중 ~~**4개**~~ **7개** ⟨반복 3⟩를 풀고 쓰러뜨린다: ① 점지 ② 상흔 ③ 명부 ④ 넋흔들림이 장수에게 **3 이상** 걸림 ⟨반복 3⟩ ⑤ 장단 3 이상으로 턴을 마침 ⑥ 굿상에 설치물이 있는 채로 턴을 마침 ⑦ 부적 카드로 장수에게 피해 ⑧ 진형이 바뀐 채로 턴을 마침. 한 번 풀린 매듭은 다시 맺히지 않는다 |
| **업경대 비추기**(바로 앞 방 고정) | 이번 원정의 해원 수: 0~4 귀기 +10 / 5~9 해원 조건 공개 + 첫 턴 드로우 +1 / **10~14 매듭 1개가 풀린 채 시작** + 체력 +15% / **15 이상 매듭 2개** + 체력 +15%. 향 1이면 한 단계 위, 만신은 해원 수 +2 |

- 매듭 넷은 어떤 3인 조합도 풀 수 있다: 영웅마다 상태 3종을 만들고(시그니처·주·부), 장단(기세)과 진형(돌격)은 모든 파티에 있다. 조합에 따라 *어떤 넷*이 쉬운지가 다를 뿐이다.
- ⟨반복 3⟩ 장수전은 평균 19턴이라 넷은 언제나 풀렸다(이기면 100% 해원). **일곱 + 상태 문턱 3** 으로 올렸다 — 이제 파티가 만들지 않는 상태 매듭은 업경대가 미리 풀어 줘야 하고, *원정 내내 해원한 기록*이 고풀이를 가른다(최종 원정 시뮬 78%).
- "고풀이처럼 맺힌 매듭을 하나씩 풀어 주자, 장수는 마침내 빗장에서 손을 떼고 스스로 문을 연다. 문 앞에서 기다리던 넋들이 차례로 들어간다." — 결말이 처형이 아니라 **배웅**이다.

## 4. 파티 구성과 지역의 궁합

- 3인 조합이 해원할 수 있는 원귀는 **최소 7종 · 중앙 9종 · 최대 11종**이다.

## 6. 재현 윤리 점검

| 항목 | 처리 |
|---|---|
| **시왕** | 적으로도, 말하는 인물로도 나오지 않는다. "시왕의 자리"라는 장소와 **판결하지 않는 거울(업경대)** 로만 나온다. 업경대는 이번 원정에서 *풀어 준 넋*을 비출 뿐 영웅을 심판하지 않는다. ⟨반복 4⟩ **고증 근거**: 무속 의례 속 시왕은 **심판하지 않는다** — 제주 시왕맞이에서 시왕과 차사는 심방의 굿을 따르고, 망인은 공수로 제 말을 한다(시왕 신앙과 시왕굿을 비교한 민속학 논문, [신과함께 출처 조사](research/lore/singwa-sources.md) S-11 ① · G-03). 「저승 재판 + 변호」 구조는 불교 시왕경 계열에 현대 법정 창작을 더한 것이고, 우리 「판결하지 않는 저승」은 무속 쪽 전승에 더 가깝다. 회랑 끝 **열넷의 빈 자리**(G-04)가 이것을 그림으로 보인다 |
| 피할 고유 요소 | 저승 재판·변호(신과함께), "49일의 시련"(7 Trials의 간판 문구), 검은 갓 저승사자(도깨비·KPDH)를 쓰지 않는다. 재판 장면·판결·변론이 없다. 검사기가 '변호사·국선·변론'을 금지어로 잡는다 |
| 사자(문사재) | 적이 아니라 *문답하는 문지기*로, 사재삼성거리의 해학 그대로. 군졸 차림(1막과 같다) |
| **최종 보스** | **신령이 아닌 큰 원귀**다. 가상 왕국 북쪽 변방의 *이름 없는* 장수 — 실존 장군(최영 등)·실제 전쟁·실제 관문을 떠올리게 하는 이름과 사건을 쓰지 않는다. 장군신으로 모셔지는 신령과 섞이지 않게 "모셔지지 못해 원귀로 남았다"는 쪽으로 그린다. 결말은 처형이 아니라 빗장을 놓고 문을 여는 배웅 |
| 무장 원귀 | 싸움터의 죽음은 "쓰러졌다"까지만. 피·상처 묘사 없음. 방패 군졸의 해원 '오랜 상처를 짚어 준다'는 마음의 상처로 연출. ⟨반복 4⟩ 의례 근거: 전란·비명에 간 넋을 *상을 차려 대접해 보내는* 낙가도전침·삼천군병질침(§3.1). 「삼천 군병」은 굿 속의 일반 명칭이며 실제 전쟁·실존 부대를 가리키지 않는다 |
| 열두 대문·길닦기·꽃밭 ⟨반복 4⟩ | 질침의 댓가지 문과 아홉 단계 길닦기는 *이미지·진행 표시*로만 빌리고 지정 굿의 절차를 재현하지 않는다(감수 등급 중간). 결말의 꽃밭(환생꽃·숨살이꽃)은 전통 서사(이공본풀이·서천꽃밭, 부안 시왕풀이의 시왕산)에서 온다. 〈신과함께〉의 법정·지옥·저승 풍경은 쓰지 않는다([출처 조사](research/lore/singwa-sources.md) §3.2) |
| 혼백 보스 | 혼·백은 일반 관념이다. 백은 *흰 그림자*로 그리고 시신·좀비 이미지를 쓰지 않는다 ⚠️ 감수 대상 |
| 바리공주 모티프 | 약수·노역·나화(꽃)·서천서역은 *물건과 이벤트 구조*로만 빌린다. 바리공주(무조신, 감수 등급 중간)를 인물로 등장시키거나 이름을 게임 문장에 쓰지 않는다("약수를 구하러 저승까지 간 옛이야기처럼"). 무가 사설 인용 없음 |
| 강림·까마귀 | 차사본풀이의 까마귀 실수와 행기못은 사건·물건으로만 쓴다. 강림을 인물로 쓰지 않는다 |
| 고풀이 | 씻김굿의 고풀이(일곱 매듭)는 *해원의 은유*로 규칙에 옮겼다. 지정 굿의 절차를 그대로 재현하지 않는다(감수 등급 중간) |
| 업경대·적패지·사자밥 | 낮은 등급(설화·일반 문화) 요소 |
| 신령 가호 | 문신·신장은 범주 이름이다. 실존 인물신 없음 |

## 9. 엔진 지원 필요 — ✅ 반복 2에서 구현

새 메커니즘 3개 + 지역 2의 **공물 행동 일반화**를 명세대로 구현했다(`src/core/engine.ts`·`data.ts`·`regions.ts`, 테스트 `tests/regions.test.ts`). 구현에서 정한 것:
- 빗장: 원귀 정의에 `cap: {n, firstPhase, whileAlive}` — passive 문장 「빗장 N」·「1단계」·졸개 이름에서 읽는다. 방어도 뒤 체력 손실만 센다(`capLost`, 적 턴 시작에 0). 상흔(적 턴)·명부 처형·붕괴 중 피해는 밖. 나화 한 송이는 0코스트 「꽃 던지기」(`common.relic_kkot`): 방어도 0 + 이번 턴 빗장 해제.

### 9.1 빗장 — 한 턴 피해 상한

| 항목 | 명세 |
|---|---|
| 규칙 | **빗장 N**: 한 플레이어 턴 동안 이 원귀가 잃는 체력의 합이 N에 닿으면, 그 턴 남은 피해는 체력을 깎지 않는다. 방어도가 막은 양은 세지 않는다(방어도는 보통처럼 먼저 깎인다). 적 턴이 시작되면 0으로 돌아간다 |
| 상한 밖 | ① **상흔**(출혈) 피해 — 적 턴 시작에 들어온다 ② **명부**(파멸) 판정 — 플레이어 턴 종료에 체력과 관계없이 쓰러뜨린다 ③ **붕괴** 상태인 동안의 모든 피해 — 붕괴가 빗장을 연다. 그래서 어느 3인 조합에도 답이 있다(상흔·명부·넋흔들림을 모두 못 만드는 영웅은 잽이·탈꾼뿐이고, 둘만으로는 3인이 안 된다) |
| 조건 | 데이터 문장: `빗장 15` · `빗장 22: 1단계에서 떠도는 백이 서 있는 동안` · `빗장 16: 1단계에서 수문 군졸이 하나라도 서 있으면`. 구현은 문장 해석보다 원귀 정의에 `cap: {n, phase?: 1, whileAlive?: enemyId}` 필드를 더하는 쪽을 권한다(이 문서를 정본으로 지역 데이터에 필드를 추가해도 된다) |
| 표시 | 의도 옆에 빗장 아이콘과 이번 턴 남은 양 |
| 가호 | 나화 한 송이: 0코스트 '꽃 던지기'(소멸) — 원귀 하나의 방어도 0 + 이번 턴 빗장 해제 |
| 봇 | 피해 예측에 상한을 적용하고, 빗장 원귀 앞에서 상흔·명부·넋흔들림 카드 가치를 올린다 |
| 쓰는 곳 | 빗장 지키는 넋(15) · 혼백이 갈린 원귀(22, 1단계 · 백 생존) · 빗장을 놓지 못한 장수(16, 1단계 · 수문 군졸 생존) · 가호 나화 한 송이 |
| 대체 동작 | 구현 전: 상한 없음(문장은 표시만). P5가 방어도만으로 약해진다 |
