## 0. 한 줄 컨셉

**함께 떠난 영웅들의 카드가 하나의 덱이 된다.
누구와 함께 가느냐가 덱의 컨셉이 되고, 한 명을 잃으면 덱도 상처를 입는다.**

## 1. 출발점과 풀어야 할 문제

| 구분 | 내용 |
|---|---|
| 근간 | **Slay the Spire**: 전투 규칙(에너지·손패·적 의도), 원정 지도, 카드 보상으로 덱을 키우는 구조 |
| 강화할 것 ① 육성 | 원정이 끝나도 영웅은 남는다. 레벨·성장 분기·장비·익힌 카드가 쌓인다 |
| 강화할 것 ② 애착 | **Darkest Dungeon**의 요소: 영웅을 키우고, 장비를 입히고, **죽을 수 있다** |
| 핵심 문제 | 덱빌딩은 "캐릭터 1명 = 덱 1개"이고, DD는 "4명 파티"다. 여러 명을 덱빌딩에 넣으면 **Chaos Zero Nightmare**처럼 각자 카드만 들고 갈 뿐 서로 연계가 없어서 *같이 가는 의미*가 사라지기 쉽다 |
| 목표 | ① 영웅마다 고유한 카드 정체성이 있고 ② 그 카드들이 **합쳐져 하나의 덱**이 되며 ③ **조합에 따라 덱의 컨셉이 달라진다** |

## 2. 디자인 기둥 (초안 — Phase 2에서 확정)

| # | 기둥 | 뜻 | 검증 방법 |
|---|---|---|---|
| P1 | **파티가 곧 덱** | 덱은 파티원의 카드로만 구성된다. 보상 카드 풀도 파티 구성에 따라 바뀐다 | 같은 영웅이 다른 조합에서 다른 역할을 하는가 |
| P2 | **자립 + 증폭** (조사 후 수정, 원안 "반쪽 엔진") | 영웅마다 혼자 도는 작은 엔진이 있고, 큰 보상은 다른 영웅이 쌓은 상태를 소비할 때 열린다. 레퍼런스 게임은 모두 자기완결형이고, 반쪽 엔진은 영구 죽음과 만나면 남은 영웅의 엔진이 멈춘다 ([조사 결론](research/findings.md)) | 시너지 매트릭스: 모든 2인 조합에 연계 1개 이상, 연계 0인 쌍 0개 |
| P3 | **몸이 있는 카드** | 카드는 주인 영웅에 묶인다. 영웅이 쓰러지거나 흔들리면 그 영웅의 카드도 영향을 받는다. 영웅을 지키는 것이 전투의 일부가 된다 | 탱커·힐러 역할이 카드 밖(진형·생존)에서도 의미가 있는가 |
| P4 | **키운 만큼 아프다** | 육성·장비·인연이 쌓이고, 죽을 수 있다. 죽음은 기록되고 유산을 남긴다 | 플레이테스트: 영웅 이름을 기억하는가, 죽음이 이야기가 되는가 |
| P5 | **읽히는 시너지** | 연계 조건은 카드 텍스트에 드러나야 한다. 숨은 시너지는 금지한다 | 카드 텍스트만 보고 조합 의도를 설명할 수 있는가 |

## 3. 검증할 핵심 가설

이 가설들은 조사(Phase 1) 결과로 수정·폐기될 수 있다.

| # | 가설 | 참고 근거(조사에서 확인) |
|---|---|---|
| H1 | **공유 상태 언어**: 모든 영웅이 함께 쓰는 상태·자원 8±2개(예: 표식·화상·출혈·방어·결의…)를 둔다. 영웅마다 *생산 2개 / 소비 1~2개*를 비대칭으로 배치해, 조합에 따라 켜지는 엔진이 달라지게 한다 | Monster Train 클랜 키워드, Cobalt Core 함선 자원 |
| H2 | **연계(Link) 키워드**: "직전에 *다른 영웅의* 카드를 냈다면 ~". 카드를 내는 순서에 파티 구성이 드러난다 | 카드게임의 콤보 키워드 계열 |
| H3 | **진형**: 전열·후열(3칸)을 둔다. 적이 누구를 치는지, 어떤 카드를 쓸 수 있는지에 영향을 준다 (DD 랭크의 단순화) | Darkest Dungeon, Roguebook |
| H4 | **인연(Bond)**: 함께 원정한 영웅 쌍의 인연이 오르면 합기 카드·패시브가 열린다. 동료의 죽음은 인연 상대에게 흔적을 남긴다 | Darkest Dungeon II 관계 시스템 |
| H5 | **덱은 원정마다 새로, 영웅은 남는다**: 원정 중 얻은 카드는 원정이 끝나면 사라진다. 대신 영웅마다 숙련한 카드 일부를 영구히 익히고, 다음 원정의 시작 덱을 익힌 카드 중에서 고른다 (DD의 "스킬 7개 중 4개 선택" 구조) | Darkest Dungeon, StS |

**파티 인원 — 3인으로 확정 (결정 D2).**
- 덱 밀도: 4인이면 영웅 1명이 덱에 기여하는 카드가 적어져 정체성이 흐려진다.
- 손패 가독성: 한 손패에 영웅 3명의 카드 정도가 읽기 좋다.
- 조합 수: 로스터 10명 기준으로 3인 조합은 120개, 4인은 210개다. 3인으로도 "조합마다 다른 덱"을 만들 여지가 충분하고, 검증 부담은 훨씬 작다.

## 4. 단계별 계획

각 단계는 **산출물 → 완료 기준 확인 → 검토** 순서로 닫는다.
막히는 결정이 없으면 검토를 기다리지 않고 다음 단계를 진행하고, 방향이 바뀌면 되돌아가 고친다.

| 단계 | 목표 | 산출물 | 완료 기준 |
|---|---|---|---|
| **0. 방향 확정** ✅ | 컨셉·기둥·범위·결정 항목 | 이 문서, `docs/research/world-tone-options.md` | 결정 D1~D6 확정 |
| **1. 레퍼런스 조사** | 평가 좋은 덱빌더의 카드를 전수 조사하고 분해한다 | 아래 1-1~1-5 | 아래 참조 |
| 1-1 대상 선정 ✅ | 평가 기준으로 거른다 | §5 | 수치 근거 확보 |
| 1-2 카드 전수 조사 ✅ | 게임별 전체 카드 → 공통 스키마 JSON (2,344개, 수량 대조 일치) | `data/research/cards/*.json` | 위키 공식 목록과 수량이 맞는다 |
| 1-3 메커닉 분해 ✅ | 모든 카드를 공통 *메커닉 원자*(피해·방어·드로우·에너지·상태 부여/소비·스케일링·소멸·생성·조건·대상)로 태깅 → 키워드 사전, 비용 대비 효율 곡선, 캐릭터별 생산/소비 프로필 | `data/research/mechanics/*`, `docs/research/mechanics-atlas.md` | 미태깅 0장, 표본 검수 통과 |
| 1-4 시스템 조사 ✅ | 다인 파티 덱 구조 비교 + DD 시스템 + CZN 반면교사 | `docs/research/systems-reference.md` | 출처가 붙은 비교표 |
| 1-5 조사 결론 ✅ | 설계 원칙 도출, 가설 H1~H5 판정 | `docs/research/findings.md` | 가설별 채택/수정/폐기 |
| **2. 핵심 규칙** 📝 v0.1 | 전투 규칙(에너지·손패·턴·의도), 공유 덱 규칙, 상태 언어 확정, 연계·진형 규칙, 영웅 쓰러짐 처리 | `docs/02-core-rules.md` | 규칙 모순 없음(종이 시뮬레이션) |
| **3. 영웅** 📝 v0.1 (세계관 보강 대기) | 초기 로스터 8명: 역할·진형·생산/소비·성장 분기 | `docs/03-heroes.md`, 시너지 매트릭스 | 모든 2인 조합에 연계 엔진 ≥1, 모든 3인 조합에 설명 가능한 컨셉 |
| **4. 카드** | 조사 데이터를 재구성해 오리지널 카드 풀 제작(영웅당 시작 5장 + 보상 풀 25~30장, 공용, 저주·상태, 인연 합기 카드) + 비용 가치 모델 | `data/cards/*.json`, `docs/04-cards.md` | 모든 카드가 가치 모델 허용 범위 안 |
| **5. 적·지도·이벤트·유물** | 1막 분량 먼저 | `docs/05-encounters.md` 등 | 1막 전투·이벤트 목록 완성 |
| **6. 메타** | 영웅 성장(레벨·분기·익힌 카드), 장비, 스트레스·트라우마, 죽음·유산, 인연, 거점, 경제 | `docs/06-meta.md` | 원정 10회 분량의 성장 곡선 표 |
| **7. 프로토타입 ①** | 화면 없는 전투 엔진 + 데이터 기반 카드 + 자동 플레이 봇으로 조합별 수치 검증 | `src/core`, `tools/sim` | 3인 조합 전체 시뮬레이션: 지배 조합·죽은 조합 없음 |
| **8. 프로토타입 ②** | 플레이 가능한 1막 (UI 포함) | 실행 가능한 빌드 | 1막을 처음부터 끝까지 플레이 가능 |
| **9. 테스트·확장** | 플레이테스트·밸런싱 반복 → 2·3막, 메타 확장 | — | — |

## 5. 조사 대상 선정 (1-1 결과)

**기준**: Steam 전체 평가 *Very Positive*(80%↑, 리뷰 1,000개↑) 이상인 덱빌딩 로그라이크.
카드 **전수 조사**는 그중 *Overwhelmingly Positive* 또는 근간 게임의 직계 후속작이면서, 다인 파티 구조와 관련이 깊은 게임으로 한정한다.
(수치: 2026-11-03 Steam 영어 리뷰 기준. MC = Metacritic)

**Tier A — 카드 전수 조사**

| Slay the Spire 2 | 91% (71,882) Very Positive · 앞서 해보기(2026-03) | — | 근간의 직계 후속작 |

## 7. 원칙: 저작권과 독창성

- 조사 데이터(다른 게임의 카드 원문)는 **분석용**이다. 출처 위키와 라이선스(CC BY-SA)를 데이터에 표기한다.
- 게임에 들어가는 카드·이름·텍스트·아트·세계관은 **모두 오리지널**로 만든다. 메커닉은 원자 단위로 분해한 뒤 우리 규칙 위에서 다시 조합한다. 특정 카드를 1:1로 옮기지 않는다.
