## 0. 규칙 한눈에

```
영웅 3명이 진형(선두·중열·후열)에 선다. 체력과 방어도는 영웅마다 따로다.
덱은 하나다. 모든 카드에는 주인(영웅)이 있다.
매 턴 에너지 3, 카드 5장. 카드를 낼 때마다 주인이 바뀌면 파티의 '기세'가 오른다.
근접 영웅은 공격하면 선두로 나선다. 적은 대부분 선두를 친다.
쓰러진 영웅의 카드는 '구조' 카드로 바뀐다. 쓰러진 영웅이 맞으면 죽을 수 있다.
```

## 1. 구성 요소

| 요소 | 규칙 |
|---|---|
| 파티 | 영웅 3명. 원정 전 거점에서 고른다 |
| 진형 | 3칸: **선두 / 중열 / 후열**. 칸마다 영웅 1명 |
| 설치물 열 | 진형 앞에 놓이는 별도 열. 최대 3개. 영웅이 소환·설치한 물체(영령·결계·덫 등)가 선다. 각자 체력이나 횟수가 있고, 턴 시작이나 끝에 발동한다 |
| 체력 | 영웅마다 따로. 원정 동안 이어진다. 전투 사이 회복은 넋 수습·길굿·해원뿐이다([탐험 규칙](05-exploration.md) §9·§10). 역할별 기준: 수호형 45 · 중간형 35 · 화력형 28 (v0.4: 포수 30 · 작두박수 36 · 잽이 33으로 조정) |
| 방어도 | 영웅마다 따로. 플레이어 턴 시작 시 0이 된다 |
| 에너지 | **파티 공유 3**. 누구의 카드에 에너지를 쓸지가 곧 결정이다 |
| 덱 | 하나. 시작 덱 = 영웅마다 **로드아웃 4장** × 3 = 12장 |
| 손패 | 매 턴 5장 드로우, 최대 10장 |
| 기세 | 파티 공유 자원(§4). 최대 5, 턴 종료 시 0 |

## 2. 카드 해부

| 항목 | 내용 |
|---|---|
| 주인 | 초상·테두리 색으로 표시. **합기 카드는 주인이 2명** |
| 비용 | 0~3, X |
| 타입 | 공격 · 기술 · 능력 · 합기 · 저주 · 상태 · 구조 · 애도 |
| 대상 | 적 하나 / 적 전체 / 무작위 적 / 아군 하나 / 주인 / 파티 전체 |
| 위치 조건 | "선두에서:" "후열에서:" — 주인이 그 칸에 있을 때만 붙는 추가 효과 |

**타입별 규칙**

| 타입 | 규칙 |
|---|---|
| 공격 | 피해를 준다. **근접 영웅이 쓰면 그 영웅이 선두로 나선다**(§3) |
| 기술 | 공격이 아닌 효과 |
| 능력 | 전투 내내 남는 효과. **주인이 쓰러지면 정지**하고, 일어나면 다시 켜진다 |
| 합기 | 주인 2명이 *둘 다 서 있을 때만* 쓸 수 있다. 연계 판정에서는 항상 "다른 주인"으로 친다. 인연으로 해금된다(Phase 6) |
| 저주·상태 | 덱을 방해한다. 스트레스(§7)나 적이 넣는다. 저주에도 주인이 있을 수 있다(그 영웅의 동요) |
| 구조·애도 | 영웅이 쓰러지거나 죽으면 그 영웅의 카드가 바뀌는 특수 카드(§6) |

**방어도의 대상**
- "방어도 N" → 카드 주인이 얻는다.
- "아군에게 방어도 N" → 영웅 하나를 고른다.
- "파티 방어도 N" → 세 영웅이 모두 얻는다.

## 3. 진형과 피격

| 규칙 | 내용 |
|---|---|
| 영웅 속성 | 영웅마다 **근접** 또는 **원거리** |
| 돌격 | 근접 영웅이 공격 카드를 쓰면 **선두로 나선다**. 나머지는 순서를 지키며 한 칸씩 밀린다 |
| 이동 효과 | 카드 키워드 *전진*(선두로), *후퇴*(후열로), *교대*(두 영웅 자리 바꾸기) |
| 적 의도 | 행동과 **대상 칸**을 표시한다: 선두 / 중열 / 후열 / 전체 / 최저 체력 / 무작위. 기본 공격은 대부분 *선두* |
| 엄호 | 키워드. "이번 턴, 지정한 아군이 받을 공격을 이 영웅이 대신 받는다" |
| 피해 처리 | 방어도 → 체력 순. 체력이 0이 되면 **쓰러짐**(§6) |

> **설계 의도**: 마지막에 누구의 공격 카드를 냈는지가 *적 턴에 누가 선두에 서는지*를 정한다.
> 수호형 영웅의 공격으로 턴을 마치면 그가 맞는다. 화력형 근접 영웅이 마지막에 공격하면 그가 맞는다.
> 순서·위치·생존이 한 결정 안에 묶인다(R4).

## 4. 연계와 기세

| 규칙 | 내용 |
|---|---|
| **연계** | 카드 키워드. "연계: [효과]" = *직전에 쓴 카드의 주인이 이 카드의 주인과 다르면* 추가 효과. 그 턴의 첫 카드는 연계가 성립하지 않는다 |
| **기세** | 카드를 낼 때 **주인이 바뀔 때마다 파티 기세 +1**(최대 5). 턴 종료 시 0 |
| 기세 소비 | 일부 영웅의 카드만 기세를 소비한다(예: "기세를 모두 쓴다. 기세 1당 피해 4"). 생산은 모두, 소비는 일부(R2) |

> 한 영웅의 카드만 몰아 쓰면 기세가 오르지 않는다. "세 명이 함께 싸운다"를 규칙이 직접 보상한다.
> 이것이 CZN식 "각자 놀기"(안티패턴 A1)에 대한 구조적 대책이다.

## 5. 공유 상태 언어 (기능 골격)

공용 상태 **7개** + 공유 매개체 **3개**(진형·설치물 열·토큰 카드) + 영웅마다 **개인 자원 1개**(Phase 3).
상태마다 *소비자*(그 상태를 터뜨려 큰 이득을 보는 영웅)는 1~2명으로 제한한다(R2).

| # | 상태 (기능명) | 붙는 곳 | 규칙 | 설계 역할 |
|---|---|---|---|---|
| S1 | **취약** | 적 | 받는 피해 +50%. 적 턴 종료 시 1 감소 | 범용 증폭. 생산자 다수, 소비 카드 없음(누구나 이득) |
| S2 | **약화** | 적·영웅 | 주는 피해 −25%. 턴 종료 시 1 감소 | 범용 방어 |
| S3 | **표식** | 적 | 쌓이고 줄지 않는다. 소비 카드가 "표식 1당 +N"으로 터뜨린 뒤 제거 | 대표적인 생산/소비 분리 축 |
| S4 | **출혈** | 적 | 적 턴 시작 시 출혈만큼 체력을 잃고 1 감소. 방어도를 무시한다 | 지속 피해 축. 소비자는 "출혈 두 배", "출혈만큼 회복" |
| S5 | **파멸** | 적 | 쌓인다. 플레이어 턴 종료 시 파멸 ≥ 현재 체력이면 그 적은 쓰러진다 | 지연 처형 축. 피해를 주는 쪽과 파멸을 쌓는 쪽이 협력 |
| S6 | **균열** | 적 | 쌓인다. 적의 *버팀* 수치에 닿으면 **붕괴**: 다음 행동 취소 + 그 턴 동안 받는 피해 +50%. 균열은 0으로 돌아가고 버팀은 1.5배가 된다 | 팀 합동 축. 여러 영웅의 타격이 모여 하나의 결과를 낸다 |
| S7 | **기세** | 파티 | §4 | 연계(순서)의 보상 화폐 |

| 매개체 | 규칙 | 설계 역할 |
|---|---|---|
| M1 **진형** | §3 | 수호·돌격·엄호·위치 조건 |
| M2 **설치물 열** | §1 | 소환·설치형 영웅의 무대. 다른 영웅이 "설치물 강화/폭발"로 소비 |
| M3 **토큰 카드** | 카드가 만들어 내는 0~1코스트 임시 카드(휘발 또는 소멸) | 생성형 영웅의 무대. 다른 영웅이 "이번 턴 토큰을 N장 썼다면" 등으로 소비 |

**키워드 예산(R11)**: 상태 7 + 매개체 3 + 카드 키워드(연계·소멸·휘발·보존·선천·전진·후퇴·교대·엄호·재사용) 10 + 개인 자원 8(영웅 8명) = **28개**. 상한 40 안에서 12개의 여유.

## 6. 쓰러짐·죽음 (R6)

```
체력 0 ─▶ [쓰러짐] ─ 피격될 때마다 사망 판정 ─▶ [사망]
             │                                      │
             └ 구조 카드 N장 사용 ─▶ [기상]           └▶ 애도 카드 ─▶ 천도굿 ─▶ 조상신 · 신물(유품) 카드
```

| 단계 | 규칙 |
|---|---|
| **쓰러짐** | 체력이 0이 되면 그 칸에 쓰러진 채로 남는다. **그 영웅의 카드 전부**(덱·손패·버린 더미)가 **구조** 카드로 바뀐다. 능력은 정지한다 |
| 구조 카드 | 0코스트 기술, 소멸. "쓰러진 [주인]을 부축한다." 이번 전투에서 **N장**을 쓰면 일어난다. N = 3, 같은 전투에서 다시 쓰러질 때마다 +1 |
| **기상** | 체력 25%로 일어난다. 남은 구조 카드는 원래 카드로 돌아온다. 원정이 끝날 때까지 *회복 중* 디버프(주는 피해 −10%) |
| **쓰러진 턴 보호** (v0.4) | 영웅이 쓰러진 **그 적 턴**에는 그 영웅을 노린 공격이 가장 앞의 서 있는 영웅에게 간다(사망 판정 없음). 다음 플레이어 턴에 구할 기회가 반드시 생긴다. 다음 적 턴부터는 쓰러진 영웅이 다시 맞는다 |
| **사망 판정** | 쓰러진 영웅이 (쓰러진 다음 적 턴부터) 피격되면 판정한다. 버틸 확률 65%로 시작해서 버틸 때마다 −10%(최저 25%). 적 의도의 대상 칸을 보고 쓰러진 영웅을 *교대·후퇴*로 빼낼 수 있다 |
| 전투가 끝났는데 쓰러져 있음 | 죽지 않는다. 체력 1로 일어나고 *중상* 디버프(야영이나 본진에서 치료할 때까지 최대 체력 −20%) |
| **전멸** | 세 영웅이 동시에 쓰러지면 원정 실패. 영웅마다 마지막 사망 판정 1회(버틸 확률 50%). 살아남은 영웅은 중상을 입고 거점으로 돌아온다 |
| **사망** | 그 영웅의 카드가 **애도** 카드로 바뀐다(0코스트 기술, 소멸, "카드 1장을 뽑는다"). 덱 압축이 버프가 되지 않게 하면서, 손해도 작게 한다 |
| **천도굿** | 야영(길굿)의 선택지, 또는 귀환 후 본진 사당에서 치른다. 애도 카드를 전부 정리하고, 그 영웅은 **조상신**이 되어 **신물(유품) 카드 1장**을 남긴다. 신물 = 그 영웅이 가장 많이 쓴 카드의 기념판. 주인은 '파티'(누가 써도 연계 판정상 다른 주인). 천도굿을 치르지 못하면 넋이 떠돌아 원정 중 *씌임*의 원인이 된다(무속: 천도를 받아야 조상신이 된다) |
| 기록 | 묘지(거점)에 이름·원정 수·사인·마지막 카드가 남는다. 인연 상대에게 슬픔·결의 판정(Phase 6) |

> **왜 이렇게 하나**: 쓰러진 영웅의 카드를 빼면 덱이 압축돼 오히려 강해진다(안티패턴 A6).
> 구조 카드는 "구할까, 공격할까"라는 선택을 만들고, N이 늘어나는 규칙이 데스 스파이럴을 늦춘다(A7).
> 사망은 즉사가 아니라 **쓰러진 뒤 맞을 때마다 판정**이므로, 플레이어에게 항상 구할 기회가 있다.

## 7. 스트레스 — 전투 쪽 인터페이스

수치·회복·괴벽은 Phase 6에서 정한다. 전투에서는 다음만 정한다.

| 규칙 | 내용 |
|---|---|
| 획득 | 적의 공포 공격, 아군이 쓰러지거나 죽음, 치명타 피격 |
| **동요 카드** | 스트레스가 임계치(50 / 100)를 넘을 때마다 **그 영웅이 주인인 저주 카드**가 덱에 들어온다(예: "망설임 — 사용 불가, 휘발"). 공유 덱에 그 영웅의 정신 상태가 보인다 |
| 100 도달 | 판정: 75% *붕괴*(영웅마다 다른 부정 효과), 25% *각성*(긍정 효과) |

## 8. 턴 진행

| 단계 | 처리 |
|---|---|
| 1. 플레이어 턴 시작 | 영웅 방어도 0 → 에너지 3 → 5장 드로우 → 턴 시작 효과(능력·설치물) |
| 2. 행동 | 카드 사용(순서 자유), 물품 사용. 기세·연계 판정 |
| 3. 플레이어 턴 종료 | 턴 종료 효과(설치물) → **파멸 판정** → 손패 버림(보존 제외) → 기세 0 |
| 4. 적 턴 | 적 턴 시작: 출혈 피해 → 적이 진형 순서대로 의도 실행 → 적 턴 종료: 취약·약화 감소 |

## 9. 보상과 덱 성장

| 규칙 | 내용 |
|---|---|
| 카드 보상 | 3장 중 1장(또는 건너뛰기). **3장은 영웅마다 1장씩** → "누구의 비중을 키울까"가 선택이 된다 |
| 보상 풀 | 출전한 영웅의 풀 + 해금된 합기 카드만(R5) |
| 강화 | 야영(길굿)에서 카드 1장 강화 |
| 제거 | 상점·이벤트. *쓰러짐·사망으로는 절대 제거되지 않는다* |
| 원정 종료 | 덱은 사라진다. 영웅마다 원정 중 가장 많이 쓴 카드 1장을 *익힌 카드*로 남길 수 있다(영속, R8). 세부는 Phase 6 |

## 10. 이름표 (세계관 확정 시 교체)

## 11. 종이 시뮬레이션 — 한 턴 (규칙 모순 점검)

**설정**

- 파티(임시 원형): 방패(근접·수호형) / 사냥꾼(원거리·표식) / 주술사(원거리·설치물·파멸)
- 진형: 선두 방패, 중열 사냥꾼, 후열 주술사. 에너지 3.
- 적 A: 체력 40, 버팀 15, 의도 "선두에게 피해 12"
- 적 B: 체력 20, 의도 "후열에게 피해 6 + 약화 1"

**손패**

| 카드 | 주인 | 비용 | 효과 |
|---|---|---|---|
| 내려찍기 | 방패 | 1 | 공격. 피해 8, 균열 4 |
| 버티기 | 방패 | 1 | 방어도 8 |
| 표식 사격 | 사냥꾼 | 1 | 공격. 피해 5, 표식 2 |
| 급소 저격 | 사냥꾼 | 2 | 공격. 피해 6 + 표식 1당 4, 표식 제거. 연계: 비용 1 감소 |
| 원혼 부르기 | 주술사 | 1 | 설치물 '원혼': 턴 종료 시 무작위 적에게 피해 3 + 파멸 2 |

**진행 A (공격 몰기)**

| 순서 | 카드 | 결과 | 기세 | 남은 에너지 |
|---|---|---|---|---|
| 1 | 표식 사격 | A에게 피해 5, 표식 2 | 0 | 2 |
| 2 | 내려찍기 | A에게 피해 8, 균열 4. 방패는 이미 선두라 그대로 | 1 | 1 |
| 3 | 급소 저격 | 연계 성립(직전 주인 방패) → 비용 1. A에게 피해 6 + 2×4 = 14 | 2 | 0 |

- A는 27 피해를 입어 체력 13이 남는다.
- 적 턴: A가 선두의 방패에게 12 → 방어도 0이라 체력 −12. B가 후열 주술사에게 6 + 약화.

**진행 B (연계 사이에 방어 끼우기)**

| 순서 | 카드 | 결과 | 기세 | 남은 에너지 |
|---|---|---|---|---|
| 1 | 표식 사격 | A에게 피해 5, 표식 2 | 0 | 2 |
| 2 | 버티기 | 방패 방어도 8 | 1 | 1 |
| 3 | 급소 저격 | 연계 성립 → 비용 1. A에게 피해 14 | 2 | 0 |

- A는 19 피해를 입어 체력 21이 남는다.
- 적 턴: 방패는 12 중 8을 막아 체력 −4.

**점검 결과**
- 연계가 "공격 사이에 무엇을 끼울까"라는 결정을 만든다. 방어 카드도 연계의 *다리*가 된다. ✅
- 원거리인 사냥꾼은 공격해도 선두로 나서지 않는다. 피격은 방패에게 간다. ✅
- 주술사 카드(원혼 부르기)를 쓰려면 다른 카드 하나를 포기해야 한다. 에너지 공유가 *누구에게 투자할지*를 결정으로 만든다. ✅
- 규칙끼리 충돌한 지점은 없다. 미결정 1건: 같은 턴에 *돌격으로 선두가 된 영웅*을 다시 교대로 뺄 수 있는지 → **가능**(이동 효과는 순서대로 적용).

## 14. 카드 해석 규칙 (v0.3 추가, Phase 4)

카드 290장을 쓰면서 드러난 해석 빈틈을 확정한다.

| 규칙 | 내용 |
|---|---|
| 위치 조건의 판정 시점 | "선두에서:" 같은 위치 조건은 **카드를 낼 때** 판정한다. 근접 공격의 돌격 이동은 효과를 처리한 뒤에 일어난다 |
| 합기 공격의 돌격 | 합기 공격 카드는 문장에서 **마지막으로 공격하는 영웅**이 근접이면 그 영웅이 선두로 나선다. 둘 다 근접이면 같은 규칙. 원거리만 공격하면 아무도 움직이지 않는다 |
| 합기와 받는소리 | 합기 카드는 받는소리 판정에서 항상 "다른 주인"이다. 합기 카드 다음 카드는 그 주인 둘 중 누구의 카드든 받는소리가 성립하지 않는다 |
| 신바람(만신) | (v0.4) 만신 카드를 낼 때마다 +1, **직전 카드도 만신 카드면 +1 더**(최대 5). 턴을 넘겨도 남는다. 5가 되면 그 자리에서 강신(이번 턴)하고 0이 된다. 공수 카드는 강신 밖에서도 쓸 수 있고 강신 중이면 효과가 커진다 (v0.3: 직전 카드도 만신일 때만 +1, 공수는 강신 중에만) |
| 가락(잽이) | 잽이 카드를 낼 때마다 자동으로 한 단계 빨라진다(굿거리 → 자진굿거리 → 당악). 턴 종료 시 한 단계 느려진다 |
| 화약(포수) | 최대 3, 턴을 넘겨도 남는다. 장전 카드로 쌓고 사격 카드가 쓴다 |
| 작두(작두박수) | 능력 카드로 오른다. 장단 2 미만으로 턴을 마치면 헛디뎌 내려서고 표시된 체력을 잃는다. 스스로 내려서는 카드는 체력을 잃지 않는다 |
| 염주(승려) | 방어도를 얻거나 피격될 때마다 자동 +1(최대 9). 카드가 굴려서 쓴다 |
| 경면주사(법사) | 매 턴 시작 시 자동 +1(최대 3, 카드로 상한 증가 가능). 부적을 만들 때 써서 붉은 부적으로 바꾼다 |

| 오라(차사) | 충전식, 최대 3. 카드가 오라를 채우고, 적을 묶을 때 1씩 쓴다. 묶인 적은 다음 행동이 약해진다 |
| 그늘 소비 | 그늘을 소비하는 카드는 차사·만신에게만 있다(어둠 파티) |
