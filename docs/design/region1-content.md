### 원귀의 한과 해원

| 원귀 | 한(사연) | 해원 장면 |
|---|---|---|
| 물에 젖은 넋 | 물가에서 발이 미끄러져 그대로 떠내려간 넋. 아직 물이 차다. | 흔들어 깨워 물 밖으로 건져 낸다 |
| 나루 물귀신 | 나루에서 배를 기다리다 빠져 죽었다. 지나가는 이의 발목을 잡는다. | 흔들린 넋이 비로소 물을 놓는다 |
| 길 잃은 객귀 | 장삿길에서 객사했다. 집으로 가는 길을 잊었다. | 길을 열어 주어 집 쪽으로 돌려보낸다 |
| 봇짐 진 객귀 | 타향에서 번 돈을 지고 돌아오다 죽었다. 봇짐을 놓지 못한다. | 이름을 불러 세우면 봇짐을 내려놓는다 |
| 허기진 넋 | 제사를 받지 못해 굶주린 넋. 차려진 상을 보면 달려든다. | 상을 차려 대접하면 배불리 먹고 떠난다 |
| 잡귀 | 이름도 사연도 남지 않은 떠돌이. 무리를 지어 다닌다. | 부적 한 장에 무리가 흩어져 제 갈 길을 간다 |
| 굿판 훼방꾼 | 굿판마다 끼어들어 장단을 흐트러뜨리던 잡귀. | 장단이 살아나면 저도 흥이 나 물러간다 |
| 곡소리 넋 | 상주 없이 떠난 넋. 제 곡을 제가 운다. | 이름을 명부에 올려 주면 곡을 그친다 |
| 누명 쓴 아전 원귀 | 장부를 맞추지 못했다는 누명으로 매를 맞다 죽은 아전. 아직도 장부를 넘긴다. | 누명을 명부에 바로잡아 적어 준다 |
| 혼처 잃은 몽달귀 | 혼례를 사흘 앞두고 죽은 총각. 혼처를 찾아 헤맨다. | 혼처를 점지해 주면 비로소 길을 떠난다 |
| 물밑 그림자 | 나루에서 빠져 죽은 이들이 뭉친 그림자. 손을 뻗어 산 사람을 끌어당긴다. | 엉킨 넋들이 흔들려 하나씩 풀려난다 |
| 삯 못 받은 뱃사공 | 평생 넋들을 건네주고도 끝내 삯을 받지 못했다. 이제 아무도 건네주지 않는다. | 밀린 삯을 치르면 마지막으로 노를 저어 스스로 강을 건넌다 |
| 넘어가지 못한 상여 | 저승 강을 건너다 멈춰 선 상여. 상여꾼들이 아직도 상여소리를 멈추지 못한다. | 상여를 끝까지 보내 주면 상여꾼들도 함께 강을 건넌다 |

## 방 이벤트

**사자 검문** — 군졸 차림의 저승사자 셋이 길을 막고 심술을 부린다. 해학이 있는 장면이다.
- 인정을 쓴다 [지전 2] → 통과 + 다음 전투 선제 확정
- 동료 차사가 말을 건넨다 [필요: chasa] → 무료 통과 + 차사와 파티원 각각 정 +1
- 버틴다 → 놀이 싸움(특수 전투): 사자 셋, 피해가 체력 대신 귀기로 들어간다. 이기면 통과 + 엽전 20, 지면 귀기 +15 후 통과

**떠오른 넋** — 물가에 사람 모양 넋전이 떠올라 있다.
- 넋을 건진다 [쌀 1, 향 1] → 선택한 영웅 쌍 정 +2, 30%: 일반 가호 1
- 지나간다 → 없음

**잘못 끌려온 사람** — 이름이 같아 잘못 끌려온 산 사람이 저승 어귀에서 헤맨다(잘못 데려간 사람 설화).
- 데려다준다 → 호위 특수 전투: 그 사람(체력 20)을 지키며 잡귀 무리를 3턴 버틴다. 성공하면 치성 +1, 실패하면 귀기 +10
- 길만 알려 준다 [향 1] → 엽전 15

**서낭 고개 신탁** — 고개 마루의 서낭당에 오색 천이 걸려 있다.
- 공수를 받는다 [필요: manshin] → 남은 방 전체 정찰
- 향을 올린다 [향 1] → 다음 방 2개 정찰
- 돌만 얹고 간다 → 귀기 −5

**헛굿 판** — 잡귀들이 모여 굿 흉내를 내며 떠들썩하다.
- 장단을 맞춰 준다 [필요: jaebi] → 뒷전: 이번 원정 동안 씌임 임계치 +10
- 상을 차려 대접한다 [쌀 2] → 이번 원정 동안 씌임 임계치 +5
- 쫓아낸다 → 전투(잡귀 ×4)

**뱃사공의 나룻배** (고정: 보스 길에서 보스 굴 바로 앞) — 삯을 받지 못한 뱃사공의 빈 배가 매여 있다.
- 노잣돈을 놓고 이야기를 듣는다 [지전 1] → 보스 해원 조건 공개 + 보스전 첫 턴 드로우 +1
- 그냥 지나간다 → 없음
