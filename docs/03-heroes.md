## 0. 원형과 개체

- **원형**(클래스) 8개: 만신 · 잽이 · 포수 · 작두박수 · 승려 · 도사 · 탈꾼 · 차사.
- **개체**: 거점에서 영입하는 사람. 원형은 같아도 개체마다 다르다(R10).
  - 이름, 출신·사연, 성격(괴벽), 익힌 카드와 그 변이, 인연
  - 같은 포수라도 "아버지를 범에게 잃은 산포수"와 "관아에서 쫓겨난 포졸"은 다른 사람이다.
- 인연(합기 카드)은 **개체 쌍**에 쌓인다. "포수와 승려"가 아니라 "돌쇠와 혜월"의 인연이다.

## 3. 영웅 시트

각 시트: 컨셉 → 개인 자원 → 혼자 도는 엔진 → 동료에게서 오는 증폭 → 시작 로드아웃 4장(개념, 수치는 Phase 4) → 성장의 길 2개(DD2 Paths 방식) → 애착 장치

### 3.1 만신 — 신을 모시는 무녀

- **컨셉**: 굿을 주재하는 강신무. 굿상에 신령을 모시고, 그 신령을 몸에 실어 싸운다.
- **개인 자원 · 신명**: 만신 카드를 쓰거나 굿상의 신령이 발동할 때 +1(최대 3). 3이 되면 *강신*을 쓸 수 있다: 굿상의 신령 하나를 몸에 실어, 이번 턴 그 신령의 능력을 두 배로 얻는다.
- **혼자**: 신령을 모시고(굿상 생산), 신명을 쌓아 강신으로 터뜨린다(굿상 소비).
- **증폭**: 동료의 **부적**을 신령께 바치면 강신이 강해진다(도사·잽이·승려·탈꾼의 부적).
- **수출**: 신령이 원귀의 이름을 **명부**에 올린다(→ 차사·승려). 신탁으로 원귀를 **점지**한다(→ 포수·탈꾼).

| 시작 카드 | 비용 | 개념 |
|---|---|---|
| 청배 | 1 | 굿상에 신령 하나를 모신다(턴 종료 시 무작위 적에게 피해) |
| 방울 흔들기 | 1 | 공격. 피해 + 명부 |
| 공수 | 1 | 적 하나에 점지 + 약화 |
| 부채 막기 | 1 | 방어도. 연계: 굿상의 신령 하나를 즉시 발동 |

- **길**: *장군신의 길*(공격적 신령, 강신 피해) / *칠성신의 길*(명부·수명·회복)
- **애착**: 신내림을 받은 사연, 모시는 몸주신이 개체마다 다르다(→ 시작 신령이 다름)

### 3.2 잽이 — 굿판의 장단을 잡는 악사

- **컨셉**: 장구·징·피리를 잡는 악사. 장단이 살아야 굿이 산다.
- **개인 자원 · 가락**: 굿거리 → 자진 → 휘모리 3단계. 잽이 카드를 쓸 때마다 한 단계 빨라지고, 단계에 따라 효과가 커진다. 휘모리에서는 이번 턴 모든 연계 효과가 두 번 발동한다. 턴 종료 시 한 단계 느려진다.
- **혼자**: 장단(기세)을 추가로 만들고, 장단을 소비해 드로우·에너지를 얻는다.
- **증폭**: 동료의 **진형**이 바뀔 때마다 장단이 오른다(춤사위에 장단을 맞춘다. 탈꾼·포수·승려·차사).
- **수출**: 청배 장단으로 신령을 **굿상**에 부른다(→ 만신·도사). 추임새("얼쑤!") **부적**(토큰)을 만든다(→ 만신·도사).

| 시작 카드 | 비용 | 개념 |
|---|---|---|
| 장구 장단 | 0 | 장단 +1, 가락 +1 |
| 징 울림 | 1 | 공격. 모든 적에게 피해 |
| 추임새 | 1 | '얼쑤' 부적 2장 생성(0코스트, 소멸: 아군 하나 방어도) |
| 장단 바꿈 | 1 | 두 아군 교대. 이번 턴 진형이 바뀔 때마다 장단 +1 |

- **길**: *장구의 길*(장단 생산 극대화) / *피리의 길*(추임새 부적, 동료 지원)
- **애착**: 대대로 악사 집안, 혹은 굿판에서 자란 고아

### 3.3 포수 — 원귀를 쫓는 사냥꾼

- **컨셉**: 산짐승 대신 원귀를 쫓는 화승총 사수. 신중하게 표적을 정하고 한 발에 끝낸다.
- **개인 자원 · 화약**: 최대 3, 턴을 넘겨 남는다. *장전* 카드로 쌓고, *사격* 카드가 소비해 피해를 키운다.
- **혼자**: 점지를 걸고(생산) 급소 저격으로 점지를 터뜨린다(소비).
- **증폭**: **넋흔들림**이 큰(또는 붕괴한) 적을 쏘면 치명타(승려·작두박수·도사).
- **수출**: 총상 **상흔**(→ 작두박수·차사). 엄호 사격으로 아군을 빼내는 **진형** 조작(→ 탈꾼·잽이).

| 시작 카드 | 비용 | 개념 |
|---|---|---|
| 조준 | 1 | 점지 + 화약 +1 |
| 화승총 사격 | 1 | 공격. 피해. 화약 1을 쓰면 피해 증가 + 상흔 |
| 급소 저격 | 2 | 공격. 점지 1당 추가 피해 후 점지 제거. 넋흔들림이 큰 적이면 두 배 |
| 엄폐 | 1 | 방어도, 후퇴 |

- **길**: *명포수의 길*(점지 저격) / *산탄의 길*(상흔·광역)
- **애착**: 가족을 범(혹은 원귀)에게 잃었다, 관아에서 쫓겨났다 등

### 3.4 작두박수 — 날 위에 선 남무

- **컨셉**: 신칼과 작두로 신령의 힘을 증명하는 남자 무당. 체력을 걸고 날 위에 선다.
- **개인 자원 · 작두**: *작두 오르기*(능력)로 작두 위에 선다. 서 있는 동안 턴 시작 시 체력 2를 잃고, 모든 공격에 피해 증가와 상흔이 붙는다. *내려오기* 카드로 내려온다.
- **혼자**: 신칼로 상흔을 새기고(생산), 상흔을 벌려 터뜨린다(소비).
- **증폭**: **장단**에 맞춰 작두를 탄다 — "칼날 춤: 장단 수만큼 반복 타격"(잽이·탈꾼).
- **수출**: 작두 위 강타가 원귀의 **넋을 흔든다**(→ 승려·포수). 장군신을 **굿상**에 모신다(→ 만신·도사).

| 시작 카드 | 비용 | 개념 |
|---|---|---|
| 신칼 베기 | 1 | 공격. 피해 + 상흔 |
| 작두 오르기 | 1 | 능력. 위 개인 자원 |
| 칼날 춤 | 1 | 공격. 작은 피해를 (장단 + 1)회 |
| 막아서기 | 1 | 방어도, 전진 |

- **길**: *작두장군의 길*(자해 → 강화) / *신칼의 길*(상흔 확산)
- **애착**: 신병을 앓다 내림굿을 받은 사연. 작두 위에서 쓰러지면 구조 카드가 하나 더 필요하다(위험한 매력)

### 3.5 승려 — 원귀를 천도하는 스님

- **컨셉**: 육환장과 염불로 원귀를 흔들고 극락으로 인도하는 스님. 파티의 방패.
- **개인 자원 · 염주**: 방어도를 얻거나 피격될 때마다 염주 알 +1(최대 9). 알을 굴려 반격·방어·진언에 쓴다.
- **혼자**: 육환장으로 넋흔들림을 쌓고(생산), 붕괴한 적에게 큰 일격을 넣는다(소비).
- **증폭**: **명부**에 오른 원귀를 천도한다 — 명부를 넋흔들림과 스트레스 회복으로 바꾼다(만신·도사·차사).
- **수출**: 엄호·자리 지키기로 **진형**을 조작한다(→ 잽이·탈꾼). 진언 **부적**(→ 만신·도사).

| 시작 카드 | 비용 | 개념 |
|---|---|---|
| 육환장 | 1 | 공격. 피해 + 넋흔들림 |
| 합장 | 1 | 큰 방어도, 염주 +1 |
| 엄호 | 1 | 이번 턴 아군 하나가 받을 공격을 대신 받는다 + 방어도 |
| 천도 염불 | 2 | 대상의 명부만큼 넋흔들림, 파티 스트레스 회복 |

- **길**: *금강의 길*(수호·반격) / *천도의 길*(명부 소비·해원·스트레스 회복)
- **애착**: 절에 버려진 아이, 전쟁에서 사람을 베고 출가한 무사 등

### 3.6 도사 — 부적을 쓰는 술사

- **컨셉**: 주사로 부적을 그려 싸우는 술사. 손패를 부적으로 채운다.
- **개인 자원 · 주사**: 매 턴 1씩 쌓인다(최대 3). 부적을 만들 때 주사를 쓰면 *붉은 부적*(강화판)이 된다.
- **혼자**: 부적을 만들고(생산), 부적을 쓴 장수로 효과를 키운다(소비).
- **증폭**: **굿상**의 신령 기운을 부적에 봉인한다 — 신령 하나를 부적 카드 여러 장으로 바꾼다(만신·잽이·작두박수).
- **수출**: 부적으로 원귀의 이름을 **명부**에 적는다(→ 차사·승려). 뇌전부로 **넋을 흔든다**(→ 승려·포수).

| 시작 카드 | 비용 | 개념 |
|---|---|---|
| 부적 쓰기 | 1 | 화부(火符) 부적 2장 생성(0코스트, 소멸: 피해) |
| 뇌전부 | 1 | 공격. 피해 + 넋흔들림 |
| 호신부 | 1 | 아군 하나 방어도. 다음 턴 부적 1장 |
| 신장 봉인 | 1 | 굿상의 신령 하나를 그 효과를 담은 부적 2장으로 바꾼다 |

- **길**: *주술의 길*(부적 대량 생산) / *둔갑의 길*(축지법·진형·회피)
- **애착**: 산에서 내려온 은둔자, 몰락한 양반가 서자 등

### 3.7 탈꾼 — 탈을 바꿔 쓰는 광대

- **컨셉**: 탈판의 광대. 자리를 바꿀 때마다 탈이 바뀌고, 탈이 바뀌면 사람도 바뀐다.
- **개인 자원 · 탈**: **진형 위치에 따라 쓰는 탈이 정해진다**.
  - 선두 = 말뚝이탈: 공격·조롱
  - 중열 = 양반탈: 약화·취약
  - 후열 = 할미탈: 회복·장단

  카드 효과가 쓰고 있는 탈에 따라 달라진다.
- **혼자**: 자리를 바꾸고(진형 생산), 위치 조건 효과를 쓴다(진형 소비).
- **증폭**: **점지**된 적을 조롱한다 — 점지된 적에게 재담 공격을 하면 취약·약화가 크게 붙는다(만신·포수·차사).
- **수출**: 춤으로 **장단**을 띄운다(→ 작두박수·잽이). 부채·쪽박 같은 소품 **부적**(→ 만신·도사).

| 시작 카드 | 비용 | 개념 |
|---|---|---|
| 말뚝이 재담 | 1 | 공격. 피해. 점지된 적이면 취약 |
| 탈 바꿔쓰기 | 0 | 아군 하나와 교대(탈이 바뀜), 장단 +1 |
| 덧뵈기 춤 | 1 | 공격. 피해. 선두에서: 2회 |
| 소품 던지기 | 1 | 소품 부적 1장 생성 + 방어도 |

- **길**: *말뚝이의 길*(선두 공격) / *할미의 길*(후열 지원·장단)
- **애착**: 사당패 출신, 양반에게 쫓겨난 재인 등. 탈 뒤의 진짜 얼굴이 원정마다 조금씩 드러난다

### 3.8 차사 — 명부를 버린 저승사자

- **컨셉**: 저승으로 데려가야 할 산 사람을 차마 데려가지 못하고 이승에 남은 저승사자. 원귀는 명부에 올려 거두고, 동료는 저승으로 보내지 않는다.
- **개인 자원 · 오랏줄**: 최대 3. 적을 묶으면(그 적의 다음 행동 약화) 하나씩 쓴다. 묶인 적에게는 명부 집행이 강해진다.
- **혼자**: 명부에 이름을 올리고(생산), 명부를 집행한다(소비. 파멸 판정).
- **증폭**: **상흔** 입은 넋을 거둔다 — 대상의 상흔만큼 명부를 더한다(포수·작두박수).
- **수출**: 명부에서 원귀의 이름을 찾아 **점지**한다(→ 포수·탈꾼). 오랏줄로 끌어당겨 **진형**을 바꾼다(→ 잽이·탈꾼).

| 시작 카드 | 비용 | 개념 |
|---|---|---|
| 오랏줄 | 1 | 공격. 피해 + 명부 |
| 명부 펼치기 | 1 | 점지 + 명부 |
| 저승 문지기 | 1 | 큰 방어도 |
| 혼 거두기 | 2 | 공격. 대상의 상흔만큼 명부 + 피해 |

- **길**: *집행의 길*(명부 처형) / *인도의 길*(쓰러진 아군의 구조 카드를 줄이고, 사망 판정을 대신 받는다 — "아직 너를 데려갈 수 없다")
- **애착**: 왜 명부를 버렸는지가 개체마다 다르다. 인도의 길은 쓰러짐·사망 규칙(핵심 규칙 §6)과 직접 맞물린다

## 4. 대표 조합 — 같은 영웅, 다른 덱

조합의 *중심 자원*(3명의 생산 × 소비가 가장 큰 자원)이 덱 컨셉을 정한다. 수치는 `synergy.py` 산출.

| 조합 | 중심 → 보조 | 덱 컨셉 |
|---|---|---|
| 만신 + 승려 + 차사 | 명부 → 넋흔들림 | **저승 명부**: 만신과 차사가 이름을 올리고, 승려가 천도로 거둔다. 느리지만 확실한 처형 |
| 잽이 + 작두박수 + 탈꾼 | 장단 → 진형 | **난장 굿판**: 탈꾼과 잽이가 장단을 올리고, 작두박수가 칼날 춤으로 터뜨린다. 근접 2명이 앞뒤를 바꾸는 고속 덱 |
| 만신 + 잽이 + 도사 | 굿상 → 부적 | **신령 상차림**: 잽이가 신령을 부르고, 만신이 강신하고, 도사가 신령을 부적으로 바꾼다. 설치물·토큰 엔진 |
| 포수 + 탈꾼 + 차사 | 점지 → 상흔 | **현상수배**: 차사와 포수가 점지하고, 탈꾼이 조롱하고, 포수가 저격한다 |
| 포수 + 작두박수 + 차사 | 상흔 → 넋흔들림 | **피의 굿**: 포수와 작두박수가 상흔을 새기고, 차사가 거둔다 |
| 포수 + 승려 + 차사 | 넋흔들림 ≈ 명부 | **사냥과 천도**: 수호 2명 + 화력 1명. 승려가 흔들고 포수가 쏘며, 남은 원귀는 명부로 |
| 잽이 + 포수 + 탈꾼 | 진형 → 점지 | **춤추는 사격대**: 자리를 바꿀 때마다 잽이 장단이 오르고, 탈꾼이 점지된 적을 놀린다 |

**같은 영웅이 조합마다 역할이 바뀌는 예 — 차사**

| 조합 | 차사의 역할 |
|---|---|
| 만신 + 승려 + 차사 | 명부의 *생산자* |
| 포수 + 작두박수 + 차사 | 상흔의 *수확자* |
| 포수 + 탈꾼 + 차사 | 점지의 *공급자* |
