# mygame — 파티 덱빌딩 로그라이크 (가제)

Slay the Spire식 덱빌딩 위에 Darkest Dungeon식 영웅 육성·장비·영구 죽음을 얹는다.
함께 원정을 떠난 영웅들의 카드가 **하나의 덱**이 되고, **조합에 따라 덱의 컨셉이 달라진다.**
